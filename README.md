## 🏫 About this project

This project provides a **complete free admissions system** for government degree colleges, built for:

> **SKR & SKR GCW(A), Kadapa, YSR District, Andhra Pradesh, India**  
> **Dr V Saleem Basha, Principal**

It includes:
- 🔹 A **WhatsApp‑based admission bot** built with **Pabbly Chatflow**.
- 🔹 A **responsive, visually attractive admissions landing page** hosted on **GitHub Pages**.

The website and bot are designed to be **free, reusable, and easy to adapt** by other colleges.

---

## 🚀 Features

✅ **WhatsApp Admissions Bot (Pabbly Chatflow)**
- Courses, fees, eligibility, and how‑to‑apply flows.  
- Lead capture (name, phone, course) synced to Google Sheets.  
- Simple, no‑code flows anyone can edit.

✅ **GitHub Pages Website**
- Modern, mobile‑friendly design.  
- Branded section for your college (name, logo, motto).  
- WhatsApp‑link buttons and “Apply now” CTAs.  
- Easy to reuse every admission season.

---

## 📥 How to use this

### 1. For your college (SKR & SKR GCW(A))

1. **Deploy the website**:  
   - Fork this repo → update `index.html` with your college details → GitHub Pages will give you a free link.  
2. **Set up WhatsApp bot**:  
   - Create a free account at **Pabbly Chatflow** → import the flows text → connect your **WhatsApp Business** number.  
3. **Share both**:  
   - WhatsApp link and GitHub Pages URL on notices, WhatsApp status, posters, and staff chats.

### 2. For other colleges

- Colleges can **clone or fork** this repo.  
- They can customize:  
  - Logo, name, courses, fees, last‑date, and WhatsApp link.  
- Everything is **free to use and adapt**.
